
# Y Combinator - Working as a Software Engineer

## Task 1: Working Fullstack - Frontend Updates Based on Feedback

This project is part of the Y Combinator Software Engineering
Job Simulation on Forage.

## Project Overview

Shiptivitas is a shipping productivity application designed
to help freight shippers manage their daily tasks.

The task focuses on improving the Shipping Requests page
by implementing a Kanban board with drag-and-drop functionality.

## Technologies

- React.js
- JavaScript
- Dragula
- Bootstrap
- CSS

## Implemented Features

- Three Kanban swimlanes: Backlog, In Progress, Complete
- All shipping requests initialized in Backlog
- Drag-and-drop between swimlanes
- Reordering cards within the same swimlane
- Automatic status updates when moving cards
- Color-coded cards based on task status
- Frontend-only state management

## Running the Project

Install dependencies:

    npm install

Start the development server:

    npm start

Open http://localhost:3000 and select Shipping Requests.
